¡Bienvenido al repositorio del Diplomado en Big Data y Data Analytics de la Universidad Iberoamericana de Ciudad de México! Este repositorio contiene los ejercicios del curso "Analítica de Datos en Python" y sus respuestas con las respectivas explicaciones.

## Descripción

Este curso está diseñado para brindarte una introducción completa a los fundamentos de la Ciencia de Datos en Python. A lo largo de este curso, se exploran diversos conceptos, técnicas y herramientas que son esenciales para trabajar en el campo de la Ciencia de Datos, cerrando con un problema integral de Machine Learning que aplica todo lo aprendido.

## Contenido

El curso se divide en 5 sesiones, cada una enfocada en un tema específico:

| Sesión | Tema |
|---|---|
| 1 | Introducción al espacio de trabajo Python: aspectos esenciales del lenguaje, Jupyter, tipos de datos, importación de archivos planos. |
| 2 | Manejo de tablas en Python: NumPy, Series y DataFrames de pandas, creación/indexado/transformación de tablas. |
| 3 | Análisis Exploratorio de Datos: limpieza de datos, `query`/`filter`/`sort_values`/`groupby`, series temporales, `pivot`/`melt`, expresiones regulares. |
| 4 | Representación gráfica de datos: matplotlib orientado a objetos, visualización estadística con seaborn, y una galería de más de 20 tipos de gráficos. |
| 5 | Resolución de un problema integral: detección de malware en APKs de Android a partir de sus permisos, aplicando EDA, agrupamiento (KMeans) y clasificación (SVM, Random Forest, KNN) con scikit-learn. |

En cada carpeta `Sesion N` encontrarás:

- Notebooks de Jupyter: ejemplos de código, ejercicios y sus respuestas explicadas.
- Conjuntos de datos: los datos usados en los ejemplos y ejercicios de esa sesión.

## Requisitos

Para sacar el máximo provecho de este curso, necesitarás tener conocimientos básicos de programación y matemáticas. Además, asegúrate de tener instaladas las siguientes herramientas:

- Python 3.x
- Jupyter Notebook (Google Colab, Visual Studio Code, PyCharm, etc.)
- Bibliotecas de Python: pandas, numpy, matplotlib, seaborn, scikit-learn, plotly
